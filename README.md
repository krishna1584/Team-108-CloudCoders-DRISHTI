## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/krishna1584/Team-108-CloudCoders-DRISHTI.git

# Navigate to project directory
cd Team-108-CloudCoders-DRISHTI

# Install dependencies
npm install

# Start the development server
npm start
```

The application will open at `http://localhost:3000` 🌐

## 🔧 Installation

### Prerequisites
- **Node.js** (version 14 or higher) 📦
- **npm** or **yarn** package manager 🔧
- **Git** for version control 🔄

### Step-by-Step Setup

1. **Clone the Repository**
   ```bash
   git clone https://github.com/krishna1584/Team-108-CloudCoders-DRISHTI.git
   cd Team-108-CloudCoders-DRISHTI
   ```

2. **Install Dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Environment Configuration**
   - Configure API endpoints in your components
   - Set up backend connection

4. **Start Development Server**
   ```bash
   npm start
   ```

5. **Build for Production**
   ```bash
   npm run build
   ```

## 💻 Usage

### 🆘 Emergency Feature
1. **Location Access**: Grant location permissions when prompted
2. **Emergency Button**: Press the large siren button on emergency page
3. **Automatic SOS**: Your location will be sent to emergency services

### 📝 Incident Reporting
1. **Navigate to Report**: Go to the incident report page
2. **Fill Details**: Enter incident information and location
3. **Submit Report**: Your report will be added to the database

### 👤 User Management
1. **Register/Login**: Create account or login with existing credentials
2. **Profile Setup**: Complete your profile information
3. **Dashboard Access**: View your reports and emergency history
